# Dataset Format — AI Training Gym

Documentation for dataset formats used in AI Training Gym.

---

## 📂 Directory Structure

```
datasets/
├── README.md              # This file
├── <dataset_name>/        # HuggingFace Dataset format
│   ├── dataset_dict.json
│   ├── train/

│   └── validation/
│       ├── data-00000-of-00001.arrow

└── <dataset_name>/
    ├── train.jsonl
    └── val.jsonl
```

---

## 📄 Supported Formats

### 1. JSONL Format (recommended for task data)

One JSON object per line, separated by `\n`.

**Math problem example:**
```jsonl
{"id": "math-001", "question": "Alice has 15 apples, Bob has 23, how many total?", "answer": 38, "steps": ["Alice has 15", "Bob has 23", "15 + 23 = 38"]}
```

**SQL injection example:**
```jsonl
{"id": "sql-get_user-fstring", "task_id": "sql-injection-fix-001", "vulnerable_code": "import sqlite3\n\ndef get_user(user_id):\n    ...", "secure_code": "import sqlite3\n\ndef get_user(user_id):\n    ...", "vulnerability": "sql_injection", "language": "python"}
```

### 2. HuggingFace Dataset Format (recommended for training)

Generated by `scripts/prepare_dataset.py`. Uses Apache Arrow columnar storage.

```python
from datasets import load_from_disk
dataset = load_from_disk("datasets/my_dataset")
print(dataset["train"][0])
```

## 📋 Field Specification

### Task Data Fields (JSONL)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | ✅ | Unique sample ID |
| `question` | string | ✅ | Input question |
| `answer` | number/string | ✅ | Expected answer |
| `steps` | string[] | ❌ | Solution steps |
| `vulnerable_code` | string | ❌ | Vulnerable code |
| `secure_code` | string | ❌ | Secure fix code |
| `task_id` | string | ❌ | Associated task ID |
| `metadata` | object | ❌ | Metadata |

### Training Data Fields (HF Dataset)

| Field | Type | Description |
|-------|------|-------------|
| `task_id` | string | Task identifier |
| `input_text` | string | Model input |
| `output_text` | string | Expected output |
| `reward` | float32 | Reward score |
| `language` | string | Programming language |
| `difficulty` | string | Difficulty level |
| `tags` | sequence[string] | Tag list |

## 🔄 Data Pipeline

```
honeycode-honeypot (raw submissions)
        ↓
scripts/prepare_dataset.py  ← mapping.yaml
        ↓
HuggingFace Dataset (Arrow)
        ↓
├── train/ → training/train_lora.py
└── validation/ → scripts/benchmark.py

generators/generate_*.py (synthetic data)
        ↓
tasks/<task-id>/data/*.jsonl → training/train_lora.py
```

---

## ⚡ Usage Tips

1. **Small datasets** (< 10,000 rows): Use JSONL, simple and direct
2. **Large datasets** (≥ 10,000 rows): Use HuggingFace Dataset format
3. **Import from honeycode-honeypot**: Use `prepare_dataset.py` with custom mapping
4. **Synthetic data**: Use generators in `generators/`
